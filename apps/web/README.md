# Web

The bridge: the Angular app that draws the overview the API serves. See the README at the top of the repository for how to run it.

For work on the screen itself, run `npm start` (or `npm run mock`) at the top of the repository in one terminal and `npm run dev:web` in another. The dev server reloads on every change and passes `/api` through to port 4757.

Tests: `npm run test -w web`.
